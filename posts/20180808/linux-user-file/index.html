Linux用户与文件基础

2018年8月8日
  • Linux

用户与用户组

任何一个文件都具有“User、Group、Others”三种身份的个别权限。
/etc/passwd  记录所有的系统上的账号与一般身份用户，以及root的相关信息;
/etc/shadow  记录个人密码;
/etc/group  记录所有的组名;

改变文件属性与权限

chgrp:   改变文件所属用户组
chown:   改变文件所有者
chmod:   改变文件的权限

数字类型改变文件权限

r:4
w:2  //让用户删除、更新、新建文件或目录
x:1  //在目录当中是与“能否进入该目录”

eg: chmod [-R] xyz 文件或目录  //xyz为rwx属性数值的相加，-R为进行递归的持续更改，即连同子目录下的所有文件都会更改

目录配置

/根目录  与开机系统有关

/bin  放置在单用户维护模式下还能够被操作的命令，重要执行文件
/boot  开机与内核文件,放置grub引导装载程序
/etc  配置文件
/lib  开机时会用到的函数库，以及在/bin或/sbin下面的命令会调用的函数库
/sbin  重要的系统执行文件，开机过程中需要的，包括开机、修复、还原系统所需要的命令。某些服务器软件程序则一般放置在/usr/sbin中，而本机自行安装的软件所产生的系统执行文件，则放置在/usr/local/sbin中

**/usr **  软件放置处，与软件安装/执行有关
/usr/bin/  绝大部分的用户可使用命令都放在这.(与/bin不同之处在于是否与开机过程相关)
/usr/include/  程序头文件与包含文件放置处
/usr/lib/  包含各应用软件的函数库、目标文件，以及不被一般用户惯用的执行文件或脚本。
/usr/local/  自行下载安装的软件建议安装的目录。
/usr/sbin/  非系统正常运行所需要的系统命令。
/usr/share/  放置共享文件
/usr/src/  放置源码

/var  主要针对常态性变动的文件，包括缓存、登陆文件以及某些软件运行所产生的文件。

/opt  第三方软件

目录与路径

目录创建与切换

绝对路径：路径的写法由根目录/写起

cd /usr/bin

相对路径：从当前目录开始写起

cd usr/bin  
cd ./usr/bin

. 代表当前的目录，也可以使用./来表示
.. 代表上一层目录，也可以用../来表示
- 代表前一个工作目录
~ 代表“目前用户身份”所在的主文件夹

处理目录的相关命令：
cd: 切换目录
pwd: 显示当前目录
mkdir: 新建一个新的目录
rmdir: 删除一个空的目录

一些常见用法：

mkdir -p github.com/hyperledger/fabric

加上-p这个参数，可以自行创建多层目录

mkdir -m 711 test

新建权限为rwx—x—x的目录

rm -r test

删除test目录下所有的文件

文件的复制、移动与删除

复制

cp [-adfilprsu] 源文件 目标文件

常用参数：
-i : 若目标文件已经存在，在覆盖时会先询问操作的进行
-r : 递归持续复制，用户目录的复制

一些常见用法：
复制/etc/目录下的所有内容到/tmp下
cp /etc/ /tmp
或cp -r /etc/ /tmp
一般源文件为目录时，需要用到-r

移动

mv [-fiu] source destination

参数：
-f : force强制的意思，若目标文件已存在，则直接覆盖
-i : 若目标文件已存在，就会询问是否覆盖
-u : 若目标文件已存在，且source比较新，才会更新

删除

rm [-fir] 文件或目录

参数：
-f : 强制删除，忽略不存在的文件，不出现警告信息
-i : 删除前询问
-r : 递归删除，删除目录文件夹，文件夹里的所有东西都会删除

文件权限以及属性

查看文件默认权限：

umask -S

新建文件：

touch newfilename

查看文件类型：

file /etc/profile

Linux磁盘与文件系统管理

文件压缩与打包

以下是几种常见的压缩文件：

*.Z compress程序压缩的文件
*.gz gzip程序压缩的文件
*.bz2 bzip2程序压缩的文件
*.tar tar程序打包的数据，并没有压缩过
*.tar.gz tar程序打包的文件，其中经过gzip的压缩
*.tar.bz2 tar程序打包的文件，其中经过bzip2的压缩

gzip和zcat

gzip可以解开compress、zip和gzip等软件所压缩的文件。gzip所新建的压缩文件为*.gz的文件名。

gzip [-cdtv`#`] 文件名 
zcat 文件名.gz

参数：
-c : 将压缩的数据输出到屏幕上，可通过数据流重定向来处理;
-d : 解压缩的参数;
-t : 可以用来检验一个压缩文件的一致性，看看文件有无错误;
-v : 可以显示出原文件/压缩文件的压缩比等信息;
-# : 压缩等级，-1最快，但是压缩比最差，-9最慢，但是压缩比最好，默认是-6.

bzip2和bzcat

bzip2比gzip提供更好的压缩比，且用法与其差不多。

bzip2 [-cdkzv`#`] 文件名
bzcat 文件名.bz2

参数：
-c : 将压缩的数据输出到屏幕上，可通过数据流重定向来处理;
-d : 解压缩的参数;
-k : 保留原文件，而不会删除原始的文件;
-z : 压缩的参数;
-v : 可以显示出原文件/压缩文件的压缩比等信息;
-# : 压缩等级，-1最快，但是压缩比最差，-9最慢，但是压缩比最好，默认是-6.

打包命令：tar

打包与压缩的用法：

tar [-j|-z] [cv] [-f 新建的文件名] filename

解压缩的用法：

tar [-j|-z] [xv] [-f 新建的文件名] [-C 目录]

参数:
-c : 新建打包文件，可搭配-v来查看过程中被打包的文件名;
-t : 查看打包文件的内容含有哪些文件名，重点在查看文件名;
-x : 解打包或压缩的功能，可以搭配-C在特定目录解开;
-j : 通过bzip2的支持进行压缩/解压缩，此时文件名最好为*.tar.bz2;
-z : 通过gzip的支持进行压缩/解压缩，此时文件名最好为*.tar.gz;
-v : 在压缩/解压缩过程中，将正在处理的文件名显示出来;
-f filename : -f 后面要接被处理的文件名，建议-f 单独写一个参数;
-C 目录 : 在特定目录解压缩
